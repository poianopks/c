1) Open Interpreter가 무엇인가요? (What is Open Interpreter?)

Open Interpreter(오픈 인터프리터)는 자연어 명령을 받아 Python/JS/Shell 코드를 자동으로 작성하고 내 컴퓨터에서 실행해 주는 오픈소스 도구입니다. “이 CSV 그래프 만들어줘” 같이 말하면 알아서 코드를 만든 뒤 실행해 결과(그래프/파일/표)를 보여줍니다.

  • 대화형(채팅)으로 지시 → 코드 자동 생성 → 실행
  • 로컬 실행(PC 안)이라 데이터 보안에 유리
  • 여러 언어 지원: Python · JavaScript · Shell

2) 스마트폰과 PC, 뭐가 달라요? (Phone vs PC)

현재 공식 스마트폰 전용 앱은 없습니다. 가장 쉬운 사용법은 PC에서 설치하고, 폰(Acode)으로 명령 메모/파일 편집/결과 확인을 도와주는 방식입니다.

✔ 추천 흐름

  1. PC에 Open Interpreter 설치/실행
  2. 폰(Acode)으로 데이터 파일 편집/업로드
  3. 필요 시 클라우드(Drive/GitHub)로 PC↔폰 동기화
  4. 결과물(이미지/CSV/리포트) 폰에서 열람

💡 대안(고급)

  • 폰의 Termux + SSH로 집 PC에 접속해 원격 사용
  • 클라우드 VM(무료 티어/학생 계정 등)에서 실행

3) PC 설치 (왕초보용) (Install on PC)

준비물: Windows/macOS/Linux PC, 인터넷, Python 3.x (설치 시 Add Python to PATH 체크)

① 명령창 열기

Windows: 시작버튼 → cmd 입력 → 실행

② 설치

pip install open-interpreter

③ 실행

interpreter

처음 인사말(Hello! I’m your Open Interpreter!)이 보이면 성공입니다.

4) 스마트폰(Acode)로 어떻게 도울까요? (Using from your phone)

  1. Acode에서 새 파일을 만들고, CSV/텍스트/메모를 작성합니다.
  2. 클라우드(구글 드라이브/GitHub)에 업로드합니다.
  3. PC에서 해당 파일을 받아 Open Interpreter에게 지시합니다.
  4. 생성된 결과(그래프 이미지/요약 텍스트)를 다시 클라우드로 올려 폰에서 확인합니다.

※ 고급: Termux에서 SSH 설치 후 집 PC에 원격 접속하면, 폰으로도 직접 명령을 내려 실행할 수 있습니다.

5) 첫 실행에 써볼 말 (Try these first)

예시 1 — 숫자 합계

Please make a list of numbers 1 to 10 and calculate the sum.

예시 2 — 막대 그래프

Please make a simple bar chart comparing Apple, Samsung, and Google.

예시 3 — CSV 요약

Read sales.csv and show a summary table and a monthly trend chart.

6) 자주 쓰는 작업 템플릿 (Templates)

CSV → 요약 + 그래프 
Load data from data.csv, clean missing values, show a summary (mean, median, std),

and draw a line chart for the 'sales' column by month. Save the chart as sales.png.
폴더 이미지 일괄 리사이즈 
In the current folder, resize all JPG/PNG images so the longest side is 1280px, and save them into a new folder named resized/.
문서 요약 + 키워드 추출 
Summarize report.txt into 5 bullet points and extract 10 important keywords.

7) 안전 · 승인 단계 (Safety & Approvals)

  • 실행 전, 제안된 코드 내용이 표시됩니다. 승인(Yes)해야 진행됩니다.
  • 낯선 파일 삭제/이동 명령은 주의하세요. 중요한 폴더는 백업을 권장합니다.
  • 의미가 불분명한 명령은 한국어로 자세히 설명해 달라고 요청하세요.

8) 문제 해결 (Troubleshooting)

설치가 안 돼요? → Python이 설치되었는지, pip가 동작하는지 확인하세요.

interpreter 명령이 없대요? → 새로 연 cmd 창에서 다시 시도하거나, pip install --upgrade open-interpreter

권한 오류? → 관리자 권한으로 실행하거나, 사용자 폴더 내에서 작업하세요.

한글 파일 경로 문제? → 경로에 공백/한글이 있으면 따옴표로 감싸 주세요. (예: "C:\\내 데이터\\sales.csv")

9) 용어 정리 (Glossary)

  • CLI: 명령어로 컴퓨터와 대화하는 창 (Command Line Interface)
  • 로컬(Local): 내 컴퓨터 안에서 돌아가는 것
  • SSH: 다른 컴퓨터(집 PC 등)에 원격으로 접속하는 방법
